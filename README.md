# SQL for QA Engineers

## Overview

This repository documents my journey learning SQL from the perspective of a future Automation QA Engineer.

The goal is to build a solid understanding of SQL queries used to validate application data during software testing.

---

- WHERE
- ORDER BY
- GROUP BY

- RIGHT OUTER JOIN

- `README` - This file

---

## Why SQL Matters in QA

QA engineers often use SQL to:

- Verify data after UI actions
- Validate API responses
- Check records in a database
- Confirm updates and deletions
- Investigate defects

Learning SQL helps testers verify not only what users see but also what happens behind the scenes.
